I started at Charles Schwab as a Tech Track Intern in the summer of 2014, came back as an Associate Software Applications Engineer in June 2015, and became a Staff Software Applications Engineer in August 2017. I left in November 2018.

## Intern, 2014

I built SQL stored procedures and SSIS packages that automated weekly business reports, and I presented mobile app concepts aimed at millennial investors to leadership.

## Associate, 2015–2017

- Enhanced full-stack financial planning apps (Java, Struts, Spring, and JavaScript) that consumed REST and SOAP services.
- Led migrations from legacy code to Spring Boot microservices on PCF.
- Improved TDD with Mockito, and expanded Bitbucket and Git Flow adoption.

That work earned the Key Contributor Award in 2016.

## Staff, 2017–2018

I led cloud service integrations with Eureka, Spring Cloud Config, and Spring Cloud Gateway, and architected distributed microservices and an event-driven integration automation framework.

## Internal OSS starters

Teams duplicated effort building service foundations and cloud integrations, which slowed adoption and consistency. I built Spring Cloud starter templates, codified the Eureka, Config, and Gateway wiring, and added an event-driven automation framework for integrations.

The result was faster bootstrap and consistent platform patterns:

- 2nd place in the company code-a-thon.
- New services adopted the standard starters, with reduced setup time.
